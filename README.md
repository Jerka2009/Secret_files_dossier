# Secret Files Dossier

Веб-проект в стиле "досье на монстров" и аномалии. Проект представляет собой страницу с каталогом сущностей из вселенных SCP, Backrooms и Minecraft, где каждый объект открывается как отдельное "досье" с описанием, классом/категорией, признаками и галереей скриншотов.

Это личный пет-проект, созданный в стиле исследовательской базы данных о сущностях, аномалиях и угрозах.

## Что это за проект?

Пользователь открывает сайт и видит список категорий:

- SCP
- Backrooms
- Minecraft

После выбора сущности отображается:

- название
- краткое описание
- иконка/портрет
- класс объекта
- дата/последнее наблюдение
- размер
- признаки/характеристики
- галерея изображений

Весь контент подгружается динамически из файлов в папке `assets`, поэтому проект легко расширять новыми сущностями.

## Основные возможности

- древовидный каталог сущностей по категориям
- динамическая загрузка карточек через JavaScript
- цветовая маркировка классов и статуса сущности
- галерея скриншотов для каждой сущности
- простая структура и лёгкая кастомизация
- идеально подходит для тематического фан-сайта или коллекции "досье"

### Как устроены сущности

Каждая сущность хранится в отдельной папке внутри `assets/entities/` и содержит файлы вроде:

- `name.txt` — название
- `description.txt` — описание
- `tags.txt` — теги/характеристики
- `icon.jpg` — иконка сущности
- `screenshots/` — изображения галереи

Категории определяются в `assets/categories/index.json` и списками сущностей в файлах `.txt`.

## Как запустить проект

Поскольку проект работает через `fetch` и локальные файлы, лучше запускать его через локальный HTTP-сервер.

### Вариант 1: Python

```bash
cd Secret_files_dossier
python -m http.server 8000
```

Затем откройте в браузере:

```text
http://localhost:8000
```

### Вариант 2: просто открыть `index.html`

Можно открыть страницу напрямую, но в некоторых браузерах это может вызвать ограничения на загрузку локальных файлов. Поэтому локальный сервер предпочтительнее.
